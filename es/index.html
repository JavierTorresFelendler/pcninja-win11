Cada ISO tiene las mismas tres opciones de instalación

  1. opción 1

    Completa

    Sistema totalmente funcional con Office, Chrome y 7-Zip.

  2. opción 2

  3. opción 3

    Vanilla

    Solo la imagen de Windows Pro de Microsoft, sin nada añadido.

Antes de instalar

  • El idioma de la ISO es siempre inglés. Pronto habrá una guía para añadir idiomas al sistema.
  • No uses las opciones de Rufus para saltarte la comprobación de hardware.
  • La instalación inicia sesión automáticamente como Administrador local. Para evitarlo, borra autounattend.xml de la raíz de la ISO.
  • Las instalaciones All-in-one necesitan internet (Office y Chrome se descargan durante la instalación). Las imágenes preinstaladas funcionan sin conexión.
  • ¿Solo necesitas Office? Usa el Office Smart Installer.
