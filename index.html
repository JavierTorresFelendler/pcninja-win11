Before you install

  • The ISO language is always English. A guide for adding system languages is coming.
  • Don't use Rufus options to bypass hardware checks.
  • Setup logs in automatically as the local Administrator. To skip that, delete autounattend.xml from the ISO root.
  • All-in-one installs need internet (Office and Chrome download during setup). Preinstalled images work offline.
  • Only need Office? Use the Office Smart Installer.
